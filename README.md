# تحديات الشلة

مجموعة ألعاب ويب للشلة. أول لعبة فيها **عين الصقر**: لعبة قنص ثلاثية الأبعاد فيها حملة بقصص في الجنوب والمدينة، وترسانة أسلحة وشخصيات بالزي السعودي، ولعب جماعي من جوال إلى جوال.

## بنية المشروع

```
index.html        هيكل الصفحة: شاشة البداية، صفحة الألعاب، مقدمة عين الصقر، القوائم، واجهة اللعب
css/style.css     كل التنسيقات (الطابع التراثي: ألوان السدو، الشُّرفات النجدية، الخطوط)
js/screens.js     التنقل بين الشاشات وشريط التحميل، ويشتغل قبل محرك الرسم حتى تظهر القوائم دائماً
js/game.js        محرك اللعبة (Three.js): العالم، الشخصيات، الأسلحة، المقذوفات، الصوت، القوائم، اللعب الجماعي
assets/models/    نماذج ثلاثية الأبعاد جاهزة (شخصية Soldier)
```

في أول `js/game.js` فهرس بأقسام الملف. للانتقال إلى أي قسم، ابحث عن `---------- <اسم القسم>`.

## التشغيل محلياً

اللعبة تستخدم وحدات JavaScript (ES modules)، فلازم تشتغل من خادم ويب، ولن تعمل إذا فتحت `index.html` بالنقر المزدوج:

```bash
npx serve .
# أو
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

ارفع المجلد كما هو على أي استضافة ملفات ثابتة (مثل GitHub Pages). لا يحتاج المشروع خطوة بناء.

## المكتبات الخارجية

- [Three.js](https://threejs.org) r160، تُحمَّل من jsDelivr عبر import map في `index.html`
- PeerJS، للعب الجماعي المباشر بين الأجهزة
- خطوط Google: ريم كوفي (العناوين)، المسيري (الواجهة)، تجوّل (النصوص)

## مصادر الشخصيات والحركة

- **شخصية Soldier** (`assets/models/soldier.glb`) وحركاتها، من أمثلة [three.js](https://github.com/mrdoob/three.js/tree/r160/examples/models/gltf). أصلها شخصية وحركات من Mixamo، ومسموح استخدامها داخل الألعاب.
- **حركات الوقوف والمشي والركض** لشخصياتنا مأخوذة من مثال Xbot في three.js (حركات Mixamo)، ومحوّلة إلى زوايا مفاصل محفوظة داخل `js/game.js`.
- باقي الشخصيات (الأجسام المنحوتة، والثوب، والشماغ، والبشت، والعباية) مبنية بالكود داخل اللعبة.

## تنسيق الكود

الكود منسّق بأداة [Prettier](https://prettier.io)، وإعداداتها في `.prettierrc`:

```bash
npx prettier --write index.html css js
```
